🏗️ 系統架構與設計理念

「確定性 Pipeline + 模板化敘述」設計，徹底避免 LLM 對財務數字產生幻覺

🤖 AI Agent 處理流程（5 步驟）

1
財報解析：PDF/Excel/CSV → 標準化財務資料（pdfplumber + 啟發式關鍵字對應）
2
比率計算：償債 / 流動 / 獲利 / 槓桿 / 成長 / 效率 — 純演算法公式
3
異常偵測：Altman Z 分數 + 7 項規則式紅旗 + YoY 變動偵測
4
健康評分：加權評分模型（償債 35% / 獲利 35% / 成長 15% / 效率 15%）
5
報告生成：模板填空式 HTML 報告，所有結論對應具體數字

🛡️ 為何沒有 Hallucination？

✓
數值層完全確定性：所有比率、Z 分數、紅旗皆由 Python 計算，無隨機性。
✓
敘述層模板化：報告文字採用「if-else 模板 + 數字填空」，不呼叫 LLM 生成。
✓
每句結論可追溯：報告中每個數字都對應到原始財報欄位，支援雙向驗證。
✓
數字一致性檢查：自動比對 AI 萃取 vs 人工覆核的差異（< 1% 為合格）。
